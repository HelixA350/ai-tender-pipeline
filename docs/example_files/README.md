## Типы файлов по назначению

### Текстовые документы
- **txt** — письма, приглашения, краткие описания
- **doc/docx** — извещения, ТЗ, договоры, методики
- **pdf** — технические задания, чертежи, сканы

### Таблицы
- **xlsx/xls** — спецификации, формы заявок, сметы, калькуляции
- **xlsm** — таблицы с макросами для автоматизации

### Изображения
- **png/jpg** — фото оборудования, шильдики, схемы

### Ссылки
- **url** — ссылки на электронные торговые площадки (ЭТП)
